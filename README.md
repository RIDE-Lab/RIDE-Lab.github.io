# RIDE Lab organization homepage

This repository publishes the RIDE Lab organization page at <https://ride-lab.github.io/>.

The site is a dependency-free bilingual research portal. `index.html` defines the semantic
content, `assets/site.css` provides the shared IntelliStream ecosystem visual language, and
`assets/site.js` implements the accessible English/Chinese language switch.

RIDE Lab develops agent-native systems research on vLLM-HUST and stewards the core
repositories of SAGE. SAGE is the IntelliStream research ecosystem's shared flagship
product and has its own product website at <https://sage.org.ai/>.
